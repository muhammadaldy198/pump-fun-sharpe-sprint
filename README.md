A paper trading bot for the [Pump.fun Sharpe Sprint — Cleanest Paper Bot Wins](https://make.fun/bounty/u-jackxyz72-pump-fun-sharpe-sprint-cleanest-03e4f532) on make.fun. It trades the replayed pump.fun bonding curves of the competition window with 10 SOL of paper capital under the `pumpfun-replay/v2` harness. Places go by hourly Sharpe ratio, not raw PnL, so the bot is tuned for steady hourly equity: judged momentum entries, ownership gates, pyramid adds only into confirmed runners, and exits that let the few real runners pay for the many small stopped-out probes.

## Run it

```sh
node main.ts
```
